# PyTorch Exercise Sets

Each set includes:
- a starter `.py` file with TODO blocks and bilingual comments (EN/UA)
- a `README.md` with task descriptions, hints, and reference links

## Recommended order

1. Tensors, indexing, broadcasting, autograd
2. Modules, linear models, training loops
3. Dataset, DataLoader, minibatches, classification
4. CNNs, eval mode, inference
5. Custom autograd, hooks, freezing, checkpointing
6. Autograd, custom loss, custom `Function`
7. Custom modules, initialization, freezing, training step
8. Dataset, DataLoader, padding, masks, sequence pooling
9. CNN residual block, hooks, pooling, accuracy
10. Attention, causal masking, tiny transformer block
